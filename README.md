# 🔥 Hashtag Roaster

Drop any hashtag — get told if Twitter is bullish, pissed, or just doesn't care.

Built with **Tweepy + Groq (Llama 3.3 70B) + Streamlit**.

---

## Accounts You Need (make these first)

| Account | Link | What it's for |
|---|---|---|
| GitHub | https://github.com | Host your code |
| X (Twitter) | https://x.com | Post your app |
| X Developer | https://developer.x.com | Get Twitter API keys |
| xAI / Groq | https://console.x.ai | Get Groq API key |
| Streamlit Cloud | https://share.streamlit.io | Host the web app free |

## Setup

### 1. Get your API keys

**Twitter Bearer Token:**
1. Go to https://developer.x.com
2. Create a new project + app
3. Copy the **Bearer Token**

**Groq API Key:**
1. Go to https://console.x.ai
2. Sign up, go to API K
